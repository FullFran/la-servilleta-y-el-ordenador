# El problema

Casi todo error de modelado grave es un error de escala:

* usar una ecuación fuera de su rango
* despreciar algo que dominaba
* refinar donde no importaba

# Las cinco escalas

1. **Longitud** — ¿sobre qué distancia cambia lo que me importa?
2. **Tiempo** — ¿cuánto espero para ver algo cambiar?
3. **Energía** — comparada con $kT$ y con la barrera
4. **Magnitud de salida** — ¿cuál es el valor típico?
5. **Incertidumbre** — ¿qué modelos puedo distinguir?

# Cómo se encuentran

* **Adimensionalizando** — el método sistemático
* **Igualando términos** — balance dominante
* **Preguntando por el mecanismo** — a menudo hay interpretación directa
* **Mirando los datos** — autocorrelación, espectro, variograma

# Y la pregunta que resuelve casi todo

\Large

Con dos escalas: **¿el cociente es grande, pequeño o de orden 1?**

\normalsize
\vspace{1em}

**Grande o pequeño** $\Rightarrow$ hay parámetro pequeño, hay aproximación

**De orden 1** $\Rightarrow$ no hay simplificación; hay que calcular

\vspace{0.8em}

\alert{Reconocer el segundo caso pronto ahorra semanas buscando una
aproximación que no existe.}
